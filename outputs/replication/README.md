# Generated replication outputs

These files are regenerated by the MATLAB scripts and committed to main
after a successful default-branch workflow run. The GitHub Actions artifact
provides an additional downloadable snapshot for 90 days.

## Numerical outputs

- irfs_q02.csv, irfs_q04.csv, irfs_q06.csv, and irfs_q08.csv:
  all 20 endogenous responses to the speculative-return shock for periods 1–40.
- irf_impact_summary.csv: first-period impact responses for money/liquidity,
  output, the price level, and inflation.
- validation_report.txt: numerical checks and the 16 comparisons against
  the historical impact-response table.

## Generated figures

figures/ contains eight MATLAB-generated PNG files: one 20-variable figure
and one four-variable core figure for each of the four productive-credit
calibrations.

## Reproducibility manifests

- runtime_manifest.txt: MATLAB release/version, Dynare version and toolbox
  checksum, source commit, calibration cases, seed, and simulation settings.
- environment_manifest.txt: runner image, operating system, installed
  system-package versions, and runtime details.
- source_model_sha256.txt: SHA-256 checksums of the four committed .mod files.
- runtime_workspace/: disposable Dynare execution copies; this directory is
  intentionally ignored by Git.

The historical reference figures in outputs/figures/ are retained separately.
They are not overwritten by the generated MATLAB figures.
